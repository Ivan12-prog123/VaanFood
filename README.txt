FOODIE - WEBSITE + DESAIN FIGMA

CARA MENJALANKAN WEBSITE
1. Ekstrak ZIP ini.
2. Buka folder Foodie_Website_dan_Desain_Figma.
3. Klik dua kali index.html atau buka melalui browser.
4. Koneksi internet diperlukan untuk font dan foto dari Unsplash.

FITUR DEMO
- 12 menu makanan/minuman/dessert dengan kategori dan pencarian.
- Keranjang belanja dan pengaturan jumlah item.
- Checkout bertahap: data pengantaran/pickup -> pembayaran -> konfirmasi.
- Pilihan pembayaran simulasi: QRIS, transfer bank, e-wallet, COD.
- Ulasan pelanggan; ulasan baru disimpan di browser menggunakan localStorage.
- Tombol utama diarahkan ke bagian/step berikutnya.

CATATAN
Ini prototype front-end. Login sungguhan, transaksi pembayaran, penyimpanan pesanan di server, notifikasi, dan pelacakan GPS real-time memerlukan backend serta integrasi layanan. Pilihan pembayaran di sini belum memproses uang sungguhan.

DESAIN FIGMA
Folder figma berisi SVG. Di Figma, buat Design File lalu drag file SVG ke canvas.
